# Computer Vision Projects

A collection of self-contained computer-vision projects. Each lives in its own
directory with its own setup script, dependencies and tests, so they can be run
independently of one another.

## Projects

| Project | What it does |
|---|---|
| [GestureControl](GestureControl/) | Control the macOS cursor and windows with hand gestures from the webcam. MediaPipe hand tracking into synthesised mouse and keyboard events. |

## Layout

Every project directory is standalone:

- its own `README.md` covering setup, usage and tuning
- its own dependency list and setup script
- its own tests, runnable without special hardware where possible

Clone the repo, change into a project directory, and follow its README.
